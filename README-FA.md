# Speaking Coach — ساخت APK با GitHub، بدون Android Studio

این بسته **کد منبع + GitHub Actions** است، نه فایل APK آماده. با آپلود صحیح فایل‌ها در GitHub، GitHub Actions از روی کد برنامه APK می‌سازد. فعلاً نیازی به نصب SDK در لپ‌تاپ ندارید.

## ۱. ساخت مخزن GitHub

1. وارد [github.com/new](https://github.com/new) شوید و وارد حساب خود شوید.
2. برای Repository name بنویسید: `SpeakingCoach`.
3. حالت **Private** را برای پروژه شخصی پیشنهاد می‌کنیم (در محدوده سهمیه رایگان GitHub Actions).
4. گزینه **Add a README file** را تیک نزنید و روی **Create repository** بزنید.

## ۲. آپلود پروژه — مهم: ZIP را مستقیماً آپلود نکنید

1. فایل ZIP ارسالی را در ویندوز Extract All کنید.
2. پوشه `SpeakingCoach_GitHub_Ready` را باز کنید. در آن باید فایل `settings.gradle`، پوشه `app` و پوشه `.github` دیده شوند.
3. در GitHub، روی **uploading an existing file** (یا **Add file → Upload files**) بزنید.
4. **محتویات داخل پوشه استخراج‌شده** را از Windows Explorer انتخاب کنید و روی صفحه Upload در مرورگر **بکشید و رها کنید**. خود فایل ZIP یا پوشهٔ مادر را آپلود نکنید.
5. مطمئن شوید پس از آپلود ساختار مخزن چنین باشد: `settings.gradle` در ریشه، `app/` در ریشه و `.github/workflows/build-apk.yml` موجود باشد.
6. پایین صفحه روی **Commit changes** بزنید.

اگر مرورگر فولدرها را هنگام آپلود قبول نکرد، از Chrome یا Edge روی کامپیوتر استفاده کنید و فولدرها را با کشیدن از File Explorer آپلود کنید. اگر باز هم نشد، از صفحه خطا تصویر بفرستید.

## ۳. ساخت APK

1. وارد مخزن GitHub خود شوید و تب **Actions** را باز کنید.
2. اگر پیغام فعال‌سازی Actions دیدید، اجازه اجرا بدهید.
3. سمت چپ **Build Speaking Coach APK** را انتخاب کنید.
4. **Run workflow → Run workflow** را بزنید. (همچنین پس از آپلود روی شاخه `main` یا `master`، ساخت به‌صورت خودکار اجرا می‌شود.)
5. روی اجرای جدید کلیک کنید. اگر همه مراحل سبز شد، پایین صفحه در بخش **Artifacts**، روی **SpeakingCoach-APK** بزنید.
6. فایل دانلودشده را باز کنید: درونش `app-debug.apk` قرار دارد. اگر مرورگر فایل ZIP دانلود کرد، ابتدا Extract کنید.
7. فایل APK را به گوشی انتقال دهید و نصب کنید. ممکن است اندروید اجازهٔ نصب از منبع مربوطه را درخواست کند؛ فقط برای فایل ساخته‌شده از مخزن خودتان اجازه دهید.

## اگر اجرا قرمز شد

در Actions روی اجرای ناموفق → مرحله قرمز کلیک کنید و از متن خطا اسکرین‌شات بفرستید. تا زمانی که اجرا سبز نشده است، هیچ APK تأییدشده‌ای نداریم.

## امکانات موجود در کد

- ۱۲ درس، ۴۸ عبارت، ۳۶ سؤال، ذخیره پاسخ و وضعیت درس در حافظه گوشی
- TTS گوشی برای تلفظ در صورت پشتیبانی دستگاه
- ورودی صوتی با برنامهٔ تشخیص گفتار گوشی؛ ممکن است نیازمند اینترنت باشد
- مربی آنلاین AI هنوز در این نسخه نیست
- Android Native Java، `compileSdk 35`، `minSdk 24`، Gradle `8.9`، Android Gradle Plugin `8.7.3`، Java `17` برای فرایند ساخت

**محدودیت:** صحت داده‌ها و ساختار فایل‌ها بررسی شده، اما بدون اجرای workflow در حساب GitHub شما و آزمایش روی گوشی نمی‌توان موفقیت ساخت یا عملکرد واقعی را تضمین کرد.
