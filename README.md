# Speaking Coach (Android Java)

Source code for the offline-first personal English speaking practice app.

Build a debug APK using GitHub Actions: **Actions → Build Speaking Coach APK → Run workflow**. Download **SpeakingCoach-APK** from the run's Artifacts after success.

This cloud build uses Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Android SDK Platform 35. The Gradle distribution is installed by the workflow, so local Android Studio / SDK and Gradle Wrapper are not required to build via GitHub.

Read [README-FA.md](README-FA.md) for step-by-step Persian instructions.
